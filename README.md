## 👨‍💻 About Me

**Infra & Application Engineer @ IDFC FIRST Bank → Data Engineering**

I work at the intersection of **applications, infrastructure, and data**, with a strong focus on building reliable and maintainable data solutions.

My current Data Engineering focus is on:

* 🐍 **Python** for data processing and automation
* 🗄️ **SQL** for data transformation, validation, and analysis
* ❄️ **Snowflake** for modern cloud data warehousing

* 📊 **Data quality, validation & reconciliation**

### 🔍 Data Engineering Principles

* **Reliable pipelines over one-off scripts**
* **Data quality before analytics**
* **Idempotent processing wherever possible**
* **Incremental loading for scalable pipelines**
* **Reusable SQL transformations**
* **Clear separation between raw, staging and analytical layers**
* **Validation and reconciliation at every critical stage**
* **Automation over manual operations**
